class algolib.algorithms.dynamic_programming.knapsack.KnapsackDP¶

Bases: object

0/1 Knapsack Dynamic Programming algorithm implementation.

Solves the 0/1 knapsack problem using dynamic programming where each item can either be included completely or not at all (no fractions allowed).

Time Complexity: O(n × W) - where n is items, W is capacity Space Complexity: O(n × W) - for the DP table

Characteristics:

  • Dynamic Programming: Uses optimal substructure

  • 0/1 constraint: Items taken completely or not at all

  • Optimal: Guarantees optimal solution

  • Table-based: Uses 2D DP table

Advantages:

  • Guarantees optimal solution

  • Handles discrete items naturally

  • Well-studied algorithm

  • Can be optimized for space

Disadvantages:

  • Pseudo-polynomial time complexity

  • High space complexity

  • Not suitable for large weights

  • More complex than greedy approaches

Example

>>> items = [
...     DPItem(10, 60, "item1"),
...     DPItem(20, 100, "item2"),
...     DPItem(30, 120, "item3")
... ]
>>> knapsack = KnapsackDP()
>>> value, selection = knapsack.solve(items, 50)
>>> print(f"Maximum value: {value}")
