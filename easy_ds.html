Easy Data Structures¶

This guide covers the fundamental data structures that form the building blocks of computer science and programming.

Overview¶

Easy data structures are the foundation upon which more complex algorithms and data structures are built. They provide basic operations for storing, accessing, and manipulating data efficiently.

Stack¶

A stack is a linear data structure that follows the Last-In-First-Out (LIFO) principle. Think of it like a stack of plates - you can only add or remove from the top.

Stack data structure implementation.

class algolib.data_structures.stack.Stack

Bases: Generic[T]

Stack data structure - LIFO (Last-In-First-Out) container.

A stack is a linear data structure that follows the Last-In-First-Out (LIFO) principle. Elements are added and removed from the same end, called the “top” of the stack.

Time Complexities:

  • push: O(1) - constant time insertion

  • pop: O(1) - constant time removal

  • peek: O(1) - constant time access to top element

  • is_empty: O(1) - constant time check

  • size: O(1) - constant time size query

Space Complexity: O(n) - where n is the number of elements in the stack

Common use cases:

  • Function call management (call stack)

  • Expression evaluation and syntax parsing

  • Backtracking algorithms

  • Undo operations in applications

  • Browser history navigation

Example

>>> stack = Stack[int]()
>>> stack.push(1)
>>> stack.push(2)
>>> stack.push(3)
>>> print(stack.peek())  # Output: 3
>>> print(stack.pop())   # Output: 3
>>> print(stack.size())  # Output: 2
is_empty() → bool

Check if the stack is empty.

Returns:

True if the stack contains no elements, False otherwise

Example

>>> stack = Stack[int]()
>>> print(stack.is_empty())  # Output: True
>>> stack.push(1)
>>> print(stack.is_empty())  # Output: False
peek() → T

Return the item at the top of the stack without removing it.

Returns:

The item at the top of the stack

Raises:

IndexError – If the stack is empty

Example

>>> stack = Stack[str]()
>>> stack.push("hello")
>>> top = stack.peek()
>>> print(top)  # Output: "hello"
>>> print(stack.size())  # Output: 1 (item still in stack)
pop() → T

Remove and return the item at the top of the stack.

Returns:

The item that was at the top of the stack

Raises:

IndexError – If the stack is empty

Example

>>> stack = Stack[int]()
>>> stack.push(42)
>>> item = stack.pop()
>>> print(item)  # Output: 42

Add an item to the top of the stack.

Parameters:

item – The item to add to the stack

Example

>>> stack = Stack[str]()
>>> stack.push("first")
>>> stack.push("second")
>>> print(stack.size())  # Output: 2
size() → int

Return the number of items in the stack.

Returns:

The number of elements currently in the stack

Example

>>> stack = Stack[int]()
>>> print(stack.size())  # Output: 0
>>> stack.push(1)
>>> stack.push(2)
>>> print(stack.size())  # Output: 2

Key Operations: - Push: Add an element to the top - Pop: Remove and return the top element - Peek: View the top element without removing it - Is Empty: Check if the stack is empty

Common Use Cases: - Function call stack in programming languages - Undo/redo functionality - Expression evaluation - Depth-first search

Queue¶

A queue is a linear data structure that follows the First-In-First-Out (FIFO) principle. Think of it like a line of people waiting - the first person to join is the first to be served.

Queue data structure implementation.

class algolib.data_structures.queue.Queue

Bases: Generic[T]

Queue data structure - FIFO (First-In-First-Out) container.

A queue is a linear data structure that follows the First-In-First-Out (FIFO) principle. Elements are added at the rear (enqueue) and removed from the front (dequeue).

Time Complexities:

  • enqueue: O(1) - constant time insertion at rear

  • dequeue: O(1) - constant time removal from front

  • peek: O(1) - constant time access to front element

  • is_empty: O(1) - constant time check

  • size: O(1) - constant time size query

Space Complexity: O(n) - where n is the number of elements in the queue

Common use cases:

  • Process scheduling in operating systems

  • Breadth-first search (BFS) traversal

  • Handling requests in web servers

  • Print queue management

  • Buffer for data streams

Example

>>> queue = Queue[int]()
>>> queue.enqueue(1)
>>> queue.enqueue(2)
>>> queue.enqueue(3)
>>> print(queue.peek())    # Output: 1
>>> print(queue.dequeue()) # Output: 1
>>> print(queue.size())    # Output: 2

True if the queue contains no elements, False otherwise

The item at the front of the queue

Example

>>> queue = Queue[str]()
>>> queue.enqueue("hello")
>>> front = queue.peek()
>>> print(front)  # Output: "hello"
>>> print(queue.size())  # Output: 1 (item still in queue)

Linked List¶

A linked list is a linear data structure where elements are stored in nodes, and each node points to the next node in the sequence.

Linked List data structure implementation.

class algolib.data_structures.linked_list.LinkedList

Bases: Generic[T]

Singly linked list data structure.

A linked list is a linear data structure where elements are stored in nodes, and each node contains data and a reference to the next node in the sequence.

Time Complexities:

  • append: O(1) - constant time insertion at end (with tail reference)

  • prepend: O(1) - constant time insertion at beginning

  • insert_at: O(n) - linear time insertion at specific position

  • remove: O(n) - linear time removal (search + removal)

  • search: O(n) - linear time search

  • size: O(1) - constant time size query

Space Complexity: O(n) - where n is the number of elements in the list

Advantages:

  • Dynamic size (grows/shrinks during runtime)

  • Efficient insertion/deletion at beginning (O(1))

  • No memory waste (allocates only what’s needed)

Disadvantages:

  • No random access (must traverse from head)

  • Extra memory overhead for storing pointers

  • Not cache-friendly due to non-contiguous memory layout

Common use cases:

  • Implementation of other data structures (stacks, queues)

  • Undo functionality in applications

  • Music playlists and browser history

  • Dynamic memory allocation

Example

>>> ll = LinkedList[int]()
>>> ll.append(1)
>>> ll.append(2)
>>> ll.prepend(0)
>>> print(list(ll))  # Output: [0, 1, 2]
>>> print(ll.size())  # Output: 3

Binary Tree¶

A binary tree is a hierarchical data structure where each node has at most two children, referred to as the left child and right child.

Binary Tree data structure implementation with traversal methods.

class algolib.data_structures.binary_tree.BinaryTree

Bases: Generic[T]

Binary Tree data structure with traversal methods.

A binary tree is a hierarchical data structure where each node has at most two children, referred to as the left child and right child.

Time Complexities:

  • insert: O(n) - worst case for unbalanced tree

  • search: O(n) - worst case for unbalanced tree

  • traversals: O(n) - visits all nodes once

  • height: O(n) - worst case for unbalanced tree

Space Complexity: O(n) - where n is the number of nodes

Traversal Methods:

  • In-order (LNR): Left subtree → Node → Right subtree

  • Pre-order (NLR): Node → Left subtree → Right subtree

  • Post-order (LRN): Left subtree → Right subtree → Node

  • Level-order (BFS): Breadth-first traversal using queue

Common use cases:

  • Expression trees for parsing mathematical expressions

  • Decision trees in AI/ML

  • File system directories

  • Database indexing

  • Huffman coding trees

Example

>>> tree = BinaryTree[int]()
>>> tree.insert(5)
>>> tree.insert(3)
>>> tree.insert(7)
>>> tree.insert(1)
>>> print(list(tree.inorder()))  # Output: [1, 3, 5, 7]
>>> print(list(tree.preorder())) # Output: [5, 3, 1, 7]

Getting Started¶

To use these data structures in your code:

from algolib.data_structures import Stack, Queue, LinkedList, BinaryTree

# Create a stack
stack = Stack[int]()
stack.push(1)
stack.push(2)
stack.push(3)

# Pop elements (LIFO order)
print(stack.pop())  # 3
print(stack.pop())  # 2
print(stack.pop())  # 1

Best Practices¶

  1. Choose the Right Structure: Consider the operations you need most frequently

  2. Memory Management: Be aware of memory usage, especially with linked structures

  3. Error Handling: Always check for empty structures before operations

  4. Type Safety: Use type hints to ensure data consistency
