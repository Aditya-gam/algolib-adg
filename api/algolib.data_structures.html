class algolib.data_structures.BinarySearchTree¶

Bases: Generic[ComparableT]

Binary Search Tree (BST) data structure.

A binary search tree is a binary tree where for each node: - All nodes in the left subtree have values less than the node’s value - All nodes in the right subtree have values greater than the node’s value - Both subtrees are also binary search trees

Time Complexities (average case for balanced tree):

  • insert: O(log n) - logarithmic insertion

  • search: O(log n) - logarithmic search

  • delete: O(log n) - logarithmic deletion

  • find_min/find_max: O(log n) - logarithmic extrema finding

Time Complexities (worst case for unbalanced tree):

  • All operations: O(n) - degenerates to linear search

Space Complexity: O(n) - where n is the number of nodes

Advantages:

  • Efficient searching, insertion, and deletion

  • In-order traversal gives sorted sequence

  • No duplicate values (by design)

  • Dynamic size

Disadvantages:

  • Can become unbalanced, leading to poor performance

  • No guaranteed O(log n) performance without balancing

  • More complex than simple arrays or lists

Common use cases:

  • Database indexing

  • Expression parsing

  • Priority queues

  • Autocomplete systems

  • File system organization

Example

>>> bst = BinarySearchTree[int]()
>>> bst.insert(5)
>>> bst.insert(3)
>>> bst.insert(7)
>>> bst.insert(1)
>>> print(list(bst.inorder()))  # Output: [1, 3, 5, 7]
>>> print(bst.search(3))        # Output: True
>>> print(bst.find_min())       # Output: 1

class algolib.data_structures.BinaryTree¶

Bases: Generic[T]

Binary Tree data structure with traversal methods.

A binary tree is a hierarchical data structure where each node has at most two children, referred to as the left child and right child.

Time Complexities:

  • insert: O(n) - worst case for unbalanced tree

  • search: O(n) - worst case for unbalanced tree

  • traversals: O(n) - visits all nodes once

  • height: O(n) - worst case for unbalanced tree

Space Complexity: O(n) - where n is the number of nodes

Traversal Methods:

  • In-order (LNR): Left subtree → Node → Right subtree

  • Pre-order (NLR): Node → Left subtree → Right subtree

  • Post-order (LRN): Left subtree → Right subtree → Node

  • Level-order (BFS): Breadth-first traversal using queue

Common use cases:

  • Expression trees for parsing mathematical expressions

  • Decision trees in AI/ML

  • File system directories

  • Database indexing

  • Huffman coding trees

Example

>>> tree = BinaryTree[int]()
>>> tree.insert(5)
>>> tree.insert(3)
>>> tree.insert(7)
>>> tree.insert(1)
>>> print(list(tree.inorder()))  # Output: [1, 3, 5, 7]
>>> print(list(tree.preorder())) # Output: [5, 3, 1, 7]

class algolib.data_structures.LinkedList¶

Bases: Generic[T]

Singly linked list data structure.

A linked list is a linear data structure where elements are stored in nodes, and each node contains data and a reference to the next node in the sequence.

Time Complexities:

  • append: O(1) - constant time insertion at end (with tail reference)

  • prepend: O(1) - constant time insertion at beginning

  • insert_at: O(n) - linear time insertion at specific position

  • remove: O(n) - linear time removal (search + removal)

  • search: O(n) - linear time search

  • size: O(1) - constant time size query

Space Complexity: O(n) - where n is the number of elements in the list

Advantages:

  • Dynamic size (grows/shrinks during runtime)

  • Efficient insertion/deletion at beginning (O(1))

  • No memory waste (allocates only what’s needed)

Disadvantages:

  • No random access (must traverse from head)

  • Extra memory overhead for storing pointers

  • Not cache-friendly due to non-contiguous memory layout

Common use cases:

  • Implementation of other data structures (stacks, queues)

  • Undo functionality in applications

  • Music playlists and browser history

  • Dynamic memory allocation

Example

>>> ll = LinkedList[int]()
>>> ll.append(1)
>>> ll.append(2)
>>> ll.prepend(0)
>>> print(list(ll))  # Output: [0, 1, 2]
>>> print(ll.size())  # Output: 3

class algolib.data_structures.Queue¶

Bases: Generic[T]

Queue data structure - FIFO (First-In-First-Out) container.

A queue is a linear data structure that follows the First-In-First-Out (FIFO) principle. Elements are added at the rear (enqueue) and removed from the front (dequeue).

Time Complexities:

  • enqueue: O(1) - constant time insertion at rear

  • dequeue: O(1) - constant time removal from front

  • peek: O(1) - constant time access to front element

  • is_empty: O(1) - constant time check

  • size: O(1) - constant time size query

Space Complexity: O(n) - where n is the number of elements in the queue

Common use cases:

  • Process scheduling in operating systems

  • Breadth-first search (BFS) traversal

  • Handling requests in web servers

  • Print queue management

  • Buffer for data streams

Example

>>> queue = Queue[int]()
>>> queue.enqueue(1)
>>> queue.enqueue(2)
>>> queue.enqueue(3)
>>> print(queue.peek())    # Output: 1
>>> print(queue.dequeue()) # Output: 1
>>> print(queue.size())    # Output: 2

class algolib.data_structures.Stack¶

Bases: Generic[T]

Stack data structure - LIFO (Last-In-First-Out) container.

A stack is a linear data structure that follows the Last-In-First-Out (LIFO) principle. Elements are added and removed from the same end, called the “top” of the stack.

Time Complexities:

  • push: O(1) - constant time insertion

  • pop: O(1) - constant time removal

  • peek: O(1) - constant time access to top element

  • is_empty: O(1) - constant time check

  • size: O(1) - constant time size query

Space Complexity: O(n) - where n is the number of elements in the stack

Common use cases:

  • Function call management (call stack)

  • Expression evaluation and syntax parsing

  • Backtracking algorithms

  • Undo operations in applications

  • Browser history navigation

Example

>>> stack = Stack[int]()
>>> stack.push(1)
>>> stack.push(2)
>>> stack.push(3)
>>> print(stack.peek())  # Output: 3
>>> print(stack.pop())   # Output: 3
>>> print(stack.size())  # Output: 2
